# flow. — Finance Tracker

A beautiful, Apple Music-inspired personal finance tracker built as a Progressive Web App (PWA).

## Features
- Apple Music style UI
- Transactions, Budgets, Savings Goals with history
- Interactive Insights
- Fully installable PWA (offline capable)

## Run
Just open `index.html`

## Install
Visit https://geekedb0ylife.github.io/flow-finance/ and click install.
